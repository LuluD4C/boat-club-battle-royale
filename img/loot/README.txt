Drop item images here to replace the drawn icons. Square PNGs with a transparent
background look best (256x256 or bigger). The file names must match:

  shield.png   Shield Potion
  medkit.png   Med Kit
  recon.png    Recon Scanner
  boogie.png   Boogie Bomb
  rocket.png   Rocket Launcher
  scar.png     Golden SCAR

Any file that's missing falls back to the built-in icon. To use other names or
paths, change the `img` field for that item in config.js.

Fortnite art belongs to Epic Games. Their fan content policy allows non-commercial
fan use, so keep the game free and don't present it as official.
